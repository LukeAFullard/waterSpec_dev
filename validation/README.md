# waterSpec Validation Suite

This directory contains the scripts and outputs for the comprehensive validation plan defined in `waterSpec_validation_plan.md`.

## Global Tolerance Policy

For $N \ge 2000$-point single-slope recovery, a test is considered to PASS if:
1. The true $\beta$ falls inside the reported bootstrap CI in $\ge 90\%$ of trials (typically 30 trials).
2. The mean point estimate across trials is within $\pm 0.15$ of the true $\beta$.

## Organization
- `common.py`: Shared utilities for generating synthetic data (colored noise, broken power laws, uneven sampling, seasonality) and recording results.
- `data/`: Saved datasets for reproducibility (if necessary).
- `plots/`: Diagnostic plots generated by validation scripts.
- `results/`: CSV files containing aggregated test results.
- `section_*/`: Individual subfolders for each section of the validation plan, containing the specific scripts and markdown reports for those tests.


## Section 6.1 Reduction Note
The full grid for 6.1 is computationally prohibitive. Reduced grid used: Beta=1, N=512, sampling={even, 30% uneven}, methods={LS theil-sen, Haar mean}, bootstrap_type={wild, pairs}.
